# Auditorium Fund Raising System

A web-based fundraising and payment tracking system developed using Core PHP, MySQL, HTML5, CSS3, and JavaScript.

## Live Demo

https://auditorium.appziac.com/

## Features

- Online fundraising system
- Payment and contributor management
- Fund collection tracking
- Total amount calculation
- Payment records
- Contributor information
- Visitor tracking
- Responsive web interface
- Admin dashboard

## Technologies

- Core PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- REST API Integration
- Composer

## Project Structure

- `admin/` – Admin dashboard and management functionality
- `index.php` – Main application page
- `load-payments.php` – Payment data handling
- `qr.jpeg` – QR payment resource
- `config.example.php` – Example database configuration
